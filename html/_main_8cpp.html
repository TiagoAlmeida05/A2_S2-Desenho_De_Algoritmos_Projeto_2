Detailed Description

Main application file for the Pallet Packing Optimization Tool.

This program allows users to load truck and pallet data from files and apply various optimization algorithms to maximize profit while respecting truck capacity constraints. It benchmarks each algorithm’s execution time and logs results into a CSV file.
